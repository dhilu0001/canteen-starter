# Campus Canteen

The app we build today. It's a canteen menu with a cart.

## Running it

Nothing to install — open the StackBlitz link your instructor gave you and it's already running.

If you're on your own machine:

```bash
npm install
npm run dev
```

## What's here

| File | What it is |
|---|---|
| `src/App.jsx` | **You work here.** Starts as plain markup. |
| `src/data/menu.js` | The menu — just data. Change a price and watch. |
| `src/styles.css` | Already styled. Leave it alone unless you want to play. |
| `solutions/` | The answer to each checkpoint. Try first, peek after. |
| `vanilla-comparison.html` | The same cart without React. Open it in a browser. |

## The four checkpoints

1. **Props** — turn repeated markup into one reusable `MenuItem`
2. **Lists** — build the whole menu from `menu.js` with `.map()`
3. **State** — an Add button that actually updates the cart
4. **Derived values** — a total that's calculated, never stored

Then you add **one feature of your own**.
